# Changelog

## 1.0.0 — 2026-10-07

First complete public research release of TRACE by Tarang Jammalamadaka.

- Shared change detector with four computational probes, learned pixelwise trust, and error prediction.
- Procedural rendering, independent simulated re-observation, and a learned follow-up value policy.
- Training, validation calibration, ablations, held-out evaluation, and policy outcome audit.
- Archived real/procedural experiment reports, split identifiers, provenance, figures, and limitations.
- Local FastAPI service, paired-image and batch CLI, evidence exports, and responsive React studio.
- Automated fresh-checkout procedural training, Python checks, frontend build, and browser verification.
- Complete setup/reproduction documentation and all-rights-reserved ownership notice.

PCD data and checkpoints trained using it are excluded from publication. This release records
unresolved detector comparisons and harmful policy actions; it makes no field-validation,
state-of-the-art, or established global-novelty claim.
